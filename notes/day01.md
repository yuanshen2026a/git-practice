# 第一天：Git 环境与第一次提交

日期：2026-11-16

## 今天学了什么

- Git Bash 是 Windows 上的类 Unix 终端，不是完整的 Linux。
- `git config` 配置的是 commit 作者信息，不是 GitHub 登录。
- `git add` 把改动放进暂存区，`git commit` 才真正保存快照。

## 我动手做了什么

- 配置了 `user.name` 和 `user.email`。
- 在 `git-practice` 里执行 `git init`，完成了 5 个 commit。
- 把 Git Bash 快捷方式放到了桌面的“学习资料”文件夹。

## 卡在哪里

- `pwd` 输出 `/`，后来知道那是 Git Bash 的根目录。
- `cd` 到项目目录后，才看到 `README.md` 等文件。

## 明天做什么

- 学 branch 和 merge：新建分支、改文件、合并回 `main`。
